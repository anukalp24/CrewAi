CrewlyAi is an AI-powered multi-agent system built using React, FastAPI, LangGraph, Deep Agents, Groq, and MongoDB. It combines an outer agent system with an inner Deep Agent architecture, where an orchestrator routes user requests to either a direct-answer LLM or specialized subagents such as Research, Coding, and Review agents for handling complex tasks. It uses MongoDB checkpointing to persist graph execution state and maintain conversation continuity. The project is currently under development, with a focus on improving agent coordination, chat management, and execution reliability.
